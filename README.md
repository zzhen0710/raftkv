# RaftKV

一个通过逐步实现学习 C++ / Linux、Raft 复制与恢复的小型 KV 项目。

当前处于文档与设计阶段，尚无 KV 源码、构建或项目测试工程。目标是固定三成员、单 Raft 组、小数据的可验证系统；版本目标不等于已实现能力。
